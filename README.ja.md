# fukui-kanko-wordcloud

福井県の観光アンケートのオープンデータを可視化する、クライアントサイドのWebアプリケーションです。自由記述の回答からインタラクティブなワードクラウドを生成し、ユーザーはエリアごとのフィードバックを探索できます。

## デモ

**https://github.com/code4fukui/fukui-kanko-wordcloud

ライブデモでは、アンケートデータを処理し、ブラウザ内で直接ワードクラウドを生成します。

## 機能

- **地理的フィルタリング**: 福井県内の特定のエリアを選択して、地域ごとのアンケートのフィードバックを表示できます。
- **クライアントサイドNLP**: [kuromoji.js](https://github.com/takuyaa/kuromoji.js/) を使用してブラウザ内で日本語の形態素解析を行い、生のテキストからキーワードを抽出します。
- **動的な可視化**: [d3-cloud](https://github.com/jasondavies/d3-cloud) を使用し、出現頻度の順位に基づいて単語のサイズが決定されるワードクラウドを描画します。
- **カテゴリ別のインサイト**: 以下の5つの自由記述の設問ごとに、個別のワードクラウドを表示します。
    - 福井県に求めるもの
    - 施設に求めるもの
    - 満足度の理由
    - 福井県内での交通手段の満足度の理由
    - 不便さの内容

## 仕組み

1. アプリケーションは、データリポジトリから集計済みのアンケートデータ (`all.csv`) を取得します。
2. ユーザーがエリアを選択すると、該当するアンケート回答がフィルタリングされます。
3. 各カテゴリについて、`kuromoji.js` が日本語テキストをトークン化し、最も頻出する名詞を抽出します。
4. その後、`d3-cloud` が単語の配置を計算し、最終的なSVGのワードクラウドとして可視化します。

## ローカルでの開発

アプリケーションをローカルで実行するには、静的ファイルサーバーを使用してリポジトリのコンテンツをホストするだけです。

このプロジェクトには、アンケートデータを事前に処理して `words.json` ファイルを生成するDenoスクリプトも含まれています。これは、事前生成されたデータを必要とする別の実装などで利用できます。

```bash
# Denoのインストールが必要です
deno run --allow-net --allow-write makeWords.js
```
